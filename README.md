# Imarc-task-manager

This repository contains a FastAPI application connected to a PostgreSQL database.we can run the application using Docker and Docker Compose.

## Requirements

- Docker (v20.10.0 or later)
- Docker Compose (v1.27.0 or later)
- PostgreSQL (link in docker-compose)

## Setup

Follow the steps below to run the application.

### 1. Clone the Repository

```bash
git clone https://github.com/anuj16102062/Imarc-task-manager.git
cd task_manager
```
### 2. Build and start 
but make sure Postgres is installed and up and running.

update .env uri and docker compose Add your username, password, and database.
docker-compose up --build
### 3.  Access the Application
            http://localhost:8000//run postman collection
